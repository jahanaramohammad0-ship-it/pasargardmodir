# 🛡 PasarGuard Guard — ربات تلگرام مدیریت و مانیتورینگ پنل پاسارگارد

## قابلیت‌ها
- 📊 داشبورد: وضعیت پنل، CPU/RAM، کاربران آنلاین، نودها و کانفیگ‌ها
- 🩺 عیب‌یابی: تشخیص مشکل + راه‌حل دقیق (دستورها و مراحل فیکس)
- 🖥 نودها: وضعیت، تأخیر، خطای نود، دکمه‌ی Reconnect
- 🌍 لوکیشن‌ها: گروه‌بندی نودها بر اساس کشور + آپتایم هر لوکیشن
- 🔗 کانفیگ‌ها: تست دسترسی TCP برای هر هاست/کانفیگ
- ⏱ آپتایم ۲۴ساعت / ۷روز / ۳۰روز برای پنل، نودها و کانفیگ‌ها
- 👥 تشخیص اتصال بیش‌ازحد (تعداد IP هم‌زمان برای هر کانفیگ)
- 📜 لاگ رویدادها و خطاهای نودها
- 🔔 اعلان قطع/وصل پنل، نود و کانفیگ (با مدت قطعی)
- 🛠 تنظیمات داخل ربات: آدرس، نام‌کاربری و رمز پنل مادر، فاصله بررسی، آستانه‌ها
- دکمه‌های شیشه‌ای (Inline Keyboard تلگرام)

## نصب
```bash
cd pasarguard-guard
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # BOT_TOKEN و ADMIN_IDS را پر کنید
python -m pgbot
```
سپس در تلگرام `/start` بزنید ← 🛠 تنظیمات ← آدرس، نام‌کاربری و رمز پنل را وارد کنید ← ✅ تست اتصال.

## اجرای دائمی (systemd)
```ini
# /etc/systemd/system/pgguard.service
[Unit]
Description=PasarGuard Guard Bot
After=network.target
[Service]
WorkingDirectory=/opt/pasarguard-guard
ExecStart=/opt/pasarguard-guard/.venv/bin/python -m pgbot
Restart=always
[Install]
WantedBy=multi-user.target
```
`systemctl enable --now pgguard`

## نکته‌های مهم
- فقط آیدی‌های داخل `ADMIN_IDS` به ربات دسترسی دارند.
- رمز پنل در دیتابیس SQLite (`data/bot.db`) ذخیره می‌شود؛ دسترسی فایل را محدود کنید (`chmod 600`). پیام حاوی رمز بعد از دریافت از چت پاک می‌شود.
- از یک ادمین sudo اختصاصی برای ربات استفاده کنید.
- تست کانفیگ‌ها TCP است و از سرور ربات انجام می‌شود؛ برای نتیجه‌ی واقعی‌تر ربات را روی سروری با مسیر شبکه‌ی مشابه کاربران اجرا کنید.
- تشخیص «اتصال بیش‌ازحد» به endpoint لیست IP آنلاین در API پنل وابسته است (پیش‌فرض: `/api/user/{username}/online-ips`). اگر نسخه‌ی شما ندارد، ربات خودش غیرفعالش می‌کند و در عیب‌یابی اطلاع می‌دهد؛ با «مسیر IP آنلاین» در تنظیمات می‌توانید مسیر درست را بدهید.
- مسیر Reconnect نود و بعضی فیلدها (مثل `message` و `status` نود) طبق مستندات عمومی API پاسارگارد نوشته شده؛ ربات چند مسیر را امتحان می‌کند، ولی چون API ممکن است بین نسخه‌ها تغییر کند، بعد از نصب یک‌بار همه‌ی بخش‌ها را تست کنید.
